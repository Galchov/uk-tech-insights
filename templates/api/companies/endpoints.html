Companies API Endpoints

Method Endpoint Description
Public Read-Only Endpoints
GET /api/companies/ List all registered tech companies
GET /api/companies/<slug>/ Retrieve a single company by slug
GET /api/companies/?search=DeepMind Search companies by name or description
GET /api/companies/?location=London Filter companies by headquarters city
GET /api/companies/?industry=AI Filter by industry name
GET /api/companies/?tech_stack=Python Filter by tech stack (technology name)
GET /api/companies/?ordering=name Sort results (e.g. by name, foundation date)
GET /api/companies/?page=2 Paginate results (10 per page)
Company Management (Admins Only)
POST /api/companies/ Create a new company
PUT /api/companies/<slug>/ Replace entire company entry
PATCH /api/companies/<slug>/ Partially update company entry
DELETE /api/companies/<slug>/ Delete a company

Example Usage


  GET /api/companies/?search=deepwave-technologies
  GET /api/companies/deepwave-technologies/
  POST /api/companies/
